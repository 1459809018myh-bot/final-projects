# 人脸识别签到系统

## 项目简介

基于OpenCV和深度学习的人脸识别签到系统，提供友好的Gradio Web界面。支持人脸注册、实时识别和签到记录管理，适用于考勤、门禁等场景。

## 主要功能

- **人脸注册**：支持上传单张或多张照片进行人脸录入
- **实时识别**：通过摄像头或上传照片进行人脸识别
- **签到记录**：自动记录签到时间和置信度
- **Web界面**：基于Gradio的友好交互界面
- **多人脸检测**：同时识别画面中的多张人脸
- **置信度显示**：显示识别结果的可信度

## 技术栈

- **计算机视觉**：OpenCV (opencv-contrib-python)
- **Web框架**：Gradio
- **数据处理**：NumPy
- **人脸识别**：基于深度学习的人脸识别算法

## 安装说明

### 环境要求

- Python 3.8+
- 摄像头（用于实时识别，可选）

### 安装步骤

1. 克隆项目到本地
```bash
git clone <repository-url>
cd 人脸识别签到
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

依赖包括：
- opencv-contrib-python >= 4.8
- numpy
- gradio >= 4.0

## 使用方法

### 启动系统

```bash
python app.py
```

系统将在浏览器中自动打开，默认地址：`http://127.0.0.1:7860`

### 注册人脸

1. 在"注册人脸"标签页中：
   - 输入人员姓名
   - 上传一张或多张清晰的正面照片
   - 建议使用正面、光线充足的照片
   - 点击"注册"按钮

2. 系统处理：
   - 自动检测照片中的人脸
   - 提取人脸特征
   - 训练识别模型
   - 保存到数据库

### 识别签到

1. 在"识别签到"标签页中：
   - **方式一**：点击"使用摄像头"进行实时拍照
   - **方式二**：上传待识别的照片

2. 识别结果：
   - 在图片上标注人脸框
   - 显示识别出的姓名
   - 显示识别置信度
   - 自动记录签到信息到 `data/attendance.csv`

### 查看签到记录

签到记录保存在 `data/attendance.csv` 文件中，包含：
- 姓名
- 签到时间
- 识别置信度

## 常见问题

### Q: 识别率低怎么办？
A: 
- 使用清晰、正面的照片注册
- 每人注册多张不同角度的照片
- 确保光线充足
- 调整识别阈值参数

### Q: 摄像头无法打开？
A: 
- 检查摄像头是否被其他程序占用
- 确认摄像头驱动正常
- 尝试使用上传图片的方式

### Q: 签到记录在哪里？
A: 
- 记录保存在 `data/attendance.csv`
- 可用Excel或其他工具打开查看
